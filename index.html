I build machine learning tools that predict what long non-coding RNAs do, using sequence alone.

My thesis is titled Development of AI-based Tools for Functional Annotation of lncRNA and its Applications. It asks a simple question. Can we read the function and location of a non-coding RNA from its sequence? I worked on this in Prof. G. P. S. Raghava's group at IIIT Delhi.

I trained as a biologist and moved into computation through programming. That shapes how I build. I want tools that a wet-lab researcher can run without writing code, and I release them as web servers with open source code.

Next, I want to apply this work to RNA-based therapeutics and translational research.

Tools

Web servers and open source code from my doctoral work.

  • CytoLNCpred

    Predicts cytoplasm-associated lncRNAs from sequence features.

  • MRSLpred

    Predicts multi-label subcellular localization of mRNA at genome scale.

  • PDACpredLLM

    Predicts pancreatic cancer biomarkers using large language models.

  • ToxinPred 3.0

    Predicts peptide toxicity and designs non-toxic analogs.

  • AfProPred

    Predicts anti-freezing proteins from evolutionary profiles.

  • PlantDRPpred

    Predicts plant disease resistance proteins.
